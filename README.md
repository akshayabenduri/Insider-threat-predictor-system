# 🕵️ Insider Threat Predictor System
**A UEBA-based security tool for real-time Windows activity monitoring.**

Developed during a Research Internship at **Supraja Technologies**.

## 🛡️ Features
- **User Behavior Analytics (UEBA)**: Monitors login patterns and process execution.
- **Hardware Security**: Real-time USB insertion detection.
- **Risk Scoring Engine**: Automated threat classification (Low/Medium/High).
- **Modular Architecture**: Separated into Monitoring Agents, FastAPI Backend, and Admin Dashboard.

## 📊 Technical Requirements
- **Language**: Python 3.10+ 
- **Libraries**: `fastapi`, `psutil`, `ttkbootstrap`, `pywin32` 
- **OS**: Windows 10/11 (for Event Log access)
